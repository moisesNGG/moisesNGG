# ¡Hola! Soy Moisés

Desarrollador de software enfocado en construir aplicaciones web robustas, desde el backend hasta la experiencia de usuario final.

## En qué trabajo

Buena parte de mi trabajo reciente está en **plataformas web de reservas y turismo**: sistemas multi-rol donde conviven un panel de administración general, paneles para propietarios/negocios y flujos de registro para nuevos usuarios. Son aplicaciones Java tradicionales (JSP/Servlets sobre Hibernate/JPA) con integración a AWS (S3 para almacenamiento de archivos, despliegues containerizados con Docker hacia ECR y Elastic Beanstalk), pensadas para manejar autenticación por niveles, subida de contenido multimedia y flujos de negocio con pagos y cupones.

También he trabajado en **sistemas de trazabilidad para cadenas agroindustriales**, como el seguimiento de un producto a lo largo de distintas etapas de producción y distribución (por ejemplo, la cadena del cacao). Este tipo de proyectos combina modelado de datos de procesos físicos, control de acceso por roles y generación de reportes/trazas auditables.

En general, disfruto trabajar en el diseño de arquitecturas por capas (controlador → servicio → DAO → entidad), integración con servicios cloud, y construir interfaces administrativas claras para usuarios no técnicos.

## AWS

AWS es la nube con la que más trabajo y disfruto trabajar. La uso en el día a día para despliegues containerizados (build de imagen → push a ECR → despliegue en Elastic Beanstalk), gestión de datos con RDS y control de acceso/permisos con IAM. También he explorado Bedrock como puerta de entrada a IA generativa dentro del ecosistema AWS.
